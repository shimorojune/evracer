sideways velocity, rear slide, front lock-up, longitudinal acceleration, left/right margins,
curvature 50/100/150/200 m ahead, progress every metre). solo-4 was extended before release
to 33 inputs (curvature 25-400 m ahead, distance to and sharpness of the next corner), so
these files don't load on solo-4 any more; they are kept as references.

- general-solo4.json: the first general driver (DAgger across tracks, 6 rounds), 21.8% average
